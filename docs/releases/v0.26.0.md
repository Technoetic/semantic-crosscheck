# v0.26.0 — runtime isolation, CLI verdict hygiene, opt-in doctor gate and packaging parity

Release date: 2026-11-15.

## What it is

This release hardens child-process environment isolation and runtime timeouts, clears unaliased stale own verdicts on
exit-code-2 CLI rejections, adds an opt-in `doctor` gate to `report`, discloses passing 0-row `expect` cases, and
aligns plugin manifests, third-party licence tables, command documents and optional-solver test guards. Default
`build` and `report` outputs on `demo/crosscheck.toml`, third-party package pins (`requirements/*.txt` and Cube
`1.8.3`), and existing `v0.21.1+` data-rules compatibility remain unchanged.

## Highlights

### CLI verdict hygiene and exit-code parity

- Early exit-code-2 rejections (`argparse` parse errors, missing `--config`, and pre-execution argument guards across
  `sxc.py`, `sql-structure`, `semantic-preflight` and `okf`) now remove an unaliased prior `result.json` of that stage
  (and `report.json` / `report.md` for `report`) when the existing file is a regular single-link file inside a real
  directory, matches no CLI or configuration input path, and decodes as an sxc receipt for that stage. Symlink,
  hardlink, input-alias and concurrent-writer replacement guards remain intact.
- `grain` now propagates `StageError` exit code 3 (`EXIT_ENV`) when the PostgreSQL DSN variable is unset or the server
  is unreachable, matching the documented environment-missing exit contract.
- `expect` surfaces standard `config.load` configuration diagnostics when `[[gold.expect]]` declares no `spec_source`,
  while retaining full path/error suppression whenever `spec_source` is present.

### Runtime isolation, bounded timeouts and SQL quoting

- `cube_run.child_env` switches from a substring-based environment denylist to an explicit OS/locale variable allowlist
  (`INHERITED_ENV_ALLOWLIST`), preventing unrelated host API tokens, cloud credentials or proxy variables from reaching
  the Node.js Cube child process.
- `db.connect` sets a bounded 30-second socket timeout (`CONNECT_TIMEOUT_S = 30`) on `pg8000.native.Connection`, and
  `owl.hermit` bounds the HermiT Java subprocess (`HERMIT_TIMEOUT_S = 60`), mapping `subprocess.TimeoutExpired` to
  `ReasonerError`.
- Closure-table queries in `closure_oracle`, `sweep` and `shape_q` now pass `naming.closure_table(...)` through
  `ident.qualified(...)`, matching the identifier-quoting contract in `SECURITY.md`.

### Opt-in `doctor` report gate and `expect` 0-row disclosure

- `report` supports `[verify] doctor_observation = "disclose" | "require"` (default `"disclose"`) and
  `sxc.py report --require-doctor`. When enabled, `doctor` becomes a required stage in `report` and must be current for
  both `config_sha256` and `engine_sha256` and pass before `report` exits 0.
- A passing `expect:<gold>[<i>]` case where expected, gold and Cube row counts are all zero now records `empty: true`
  in check `detail` and appends an explicit `not_proven` line in `expect/result.json`.

### Packaging, third-party notices and command documentation parity

- `.codex-plugin/plugin.json` condenses `interface.longDescription` to a concise summary (enforced at `<= 1200`
  characters in `tests/test_packaging.py`).
- `THIRD_PARTY.md` adds `pglast 7.22` (`GPL-3.0-or-later`, optional `requirements/sql-structure.txt`) to the Python
  packages table, with pin parity enforced for both `witness.txt` and `sql-structure.txt`.
- Z3-dependent tests in `tests/test_constraint_audit.py` and `tests/test_search_extensions.py` skip cleanly when
  `z3-solver` is absent unless `SXC_TEST_FULLSTACK=1` is set.
- `sxc.py` lists all 21 stages in its module docstring, all 21 `commands/*.md` files carry plugin-rooted paths and the
  Codex `${CLAUDE_PLUGIN_ROOT}` note, and `README.md` includes a tag-pinned Claude Code clone/install option.

## Known limitations

- `cube-replay` retains its `Result(status = "not_run", reason = "runtime_dependency_or_connection_failed")` contract
  (exit code 1) when its dedicated scratch database DSN is unset or unreachable rather than exiting with code 3.
- An unsafe input alias or symlinked output path still preserves the existing file without unlinking it on exit code 2;
  callers and agents must still check the command exit code before trusting files on disk.
- `[verify] doctor_observation` defaults to `"disclose"` for backward compatibility; `report` requires `doctor` only
  when `"require"` or `--require-doctor` is opted into.
- Cube remains pinned at `1.8.3` in this release; upstream Cube pin evaluation is tracked separately.
- Existing verification limits remain: checks between generated layers share configuration mistakes, measures have no
  independent recomputation, and gold, Cube and replay reads do not share one PostgreSQL MVCC snapshot.
