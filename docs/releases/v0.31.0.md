# semantic-crosscheck v0.31.0 — small-sample paired statistics, CI static gates and repository governance

Release date: 2026-11-21.

## What it is

This release adds standard-library small-sample statistics to the offline paired release comparator, adds pinned CI-only static quality checks and a UTF-8 BOM guard, expands macOS unit CI to cover Apple Silicon (`macos-15`) alongside Intel (`macos-15-intel`), and aligns repository governance (`main` branch protection, `refs/tags/v*` immutable tag ruleset, Dependabot security updates). Runtime Python requirements and the Cube adapter lockfile are unchanged.

## Highlights

- **Small-sample paired statistics (`tools/paired_release.py`):** Each exposure group now includes `statistics.detections` and `statistics.false_positives` computed with Python's standard library (`math.comb`, `statistics.NormalDist`) only: exact conditional and Mid-P McNemar two-sided p-values (Fagerland et al., 2013), Newcombe (1998) Method 10 paired Wilson 95% confidence intervals for `candidate_rate - baseline_rate`, and explicit minimum discordant-pair bounds (`5` for Mid-P `p < 0.05`, `6` for exact `p < 0.05`) with `underpowered_for_*` flags. On the frozen v0.30.0 held-out error table (`n=3`, `a=1, b=2, c=0, d=0`), the tool reports `exact_mcnemar_p = 0.5`, `midp_mcnemar_p = 0.25`, `diff_ci_95 = [-0.058569, 0.938508]`, and `underpowered_for_midp_005 = true`, disclosing that the five held-out examples are a deterministic feature check rather than statistical significance.
- **Experimental hygiene guidance (`docs/paired-release.md`):** Documents paired evaluation methodology, small-sample interpretation, deduplication and exposure separation with references to Fagerland et al. (2013), Newcombe (1998), Dietterich (1998), Arcuri & Briand (2014) and Klees et al. (CCS 2018).
- **UTF-8 BOM guard and cleanup (`tools/check_bom.py`):** Removes UTF-8 BOM bytes from three test files (`tests/test_contract_evidence.py`, `tests/test_gold_metadata.py`, `tests/test_shacl_corpus.py`) and enforces zero tracked BOM files in unit tests and CI hygiene.
- **CI-only static quality job and Apple Silicon macOS CI (`.github/workflows/tests.yml`):** Adds a `static quality checks` job pinned to `ruff==0.17.6`, `ty==0.0.107` (curated core/tool modules) and `sqruff==0.44.0` (PostgreSQL semantic SQL lint on `demo/gold/*.sql` via `.sqruff`), and adds `macos-15` (Arm64) to the Python 3.11 / 3.13 unit matrix (11 CI jobs total).
- **Repository governance:** Enables `main` branch protection requiring all 11 CI checks (`enforce_admins`), the `refs/tags/v*` immutable tag ruleset (`release-tags-immutable`), and Dependabot security updates.

## Install

For the developer tools, clone the tagged source with `git clone --branch v0.31.0 --depth 1 https://github.com/Technoetic/semantic-crosscheck.git`. To install the plugin with Codex:

```text

codex plugin add semantic-crosscheck@semantic-crosscheck-local
```

## Known limitations

- The `paired_release.py` statistics assume independent cases within an exposure stratum; near-duplicate synthetic cases derived from one schema do not represent independent production samples.
- `ty` (`0.0.107`) is pre-1.0 and currently checks a curated list of clean core and tool modules rather than the entire codebase. `sqruff` checks PostgreSQL syntax and non-layout lint rules on `demo/gold/*.sql` only and does not establish SQL semantic equivalence.
- Operational engine behavior, runtime requirements (`requirements/*.txt`) and the Cube `1.8.3` adapter lockfile are unchanged; the five upstream npm advisories in the Cube adapter tree remain unresolved even on Cube `1.8.30` and require upstream dependency updates or explicit overrides.
- `semantic_crosscheck/__init__.py` version increments to `0.31.0`, which updates `engine_sha256` in stage provenance; rerun operational stages after upgrading.
