# semantic-crosscheck v0.31.1 — reproducible SOURCE_DATE_EPOCH archives, invisible Unicode guard, PG 17 built-in collation and CI supply-chain gates

Release date: 2026-11-21.

## What it is

This patch release replaces timezone-dependent `git archive` release ZIP creation with a standard-library `SOURCE_DATE_EPOCH` UTC archive builder, adds a standard-library guard against Trojan Source bidirectional controls and dangerous `Default_Ignorable` invisible smuggling code points, documents and tests PostgreSQL 17's built-in `C.UTF-8` collation for deterministic code-point sorting, and adds pinned CI-only workflow, supply-chain, CycloneDX SBOM and code hygiene checks while expanding `ty` coverage to 41 clean modules. Operational engine behavior, runtime Python requirements (`requirements/*.txt`) and the Cube adapter lockfile are unchanged.

## Highlights

- **Timezone-independent deterministic release archive (`tools/build_release_zip.py`):** Builds release ZIPs from `git archive --format=tar <ref>` with `SOURCE_DATE_EPOCH` (defaulting to the target commit timestamp) converted in UTC (`time.gmtime`), sorted POSIX entry paths, fixed Unix metadata (`create_system = 3`), preserved executable bits, and deflate level `-9`. Unit tests (`tests/test_build_release_zip.py`) verify byte-identical SHA-256 digests across `TZ=KST-9`, `TZ=UTC0`, and `TZ=EST5` and fail-closed rejection of pre-1980 epochs.
- **Invisible Unicode and Bidi smuggling guard (`tools/check_unicode.py`):** Rejects Trojan Source bidirectional overrides/isolates/marks (`U+061C`, `U+200E`–`U+200F`, `U+202A`–`U+202E`, `U+2066`–`U+2069`) and dangerous `Default_Ignorable` smuggling code points (`U+00AD`, `U+034F`, `U+115F`–`U+1160`, `U+180E`, `U+200B`–`U+200D`, `U+2060`–`U+2064`, `U+3164`, `U+FFA0`, `U+FEFF`, Unicode Tags `U+E0000`–`U+E007F`, Variation Selectors Supplement `U+E0100`–`U+E01EF`) in tracked repository files or explicit config/SQL/rule paths while allowing normal UTF-8 (including Korean). Reports only file path, line, column and code point — never file contents. Enforced in `tests/test_check_unicode.py` and the CI `hygiene` job.
- **PostgreSQL 17 built-in `C.UTF-8` collation guidance and integration test (`docs/data-rules.md`, `skills/semantic-crosscheck/references/pitfalls.md`, `docs/setup-roles.sql`, `tests/test_collation_builtin_pg.py`):** Documents `provider = builtin, locale = 'C.UTF-8'` as the recommended deterministic, OS `glibc`/ICU-drift-free collation for new dedicated databases and comparison views. The PostgreSQL 17 integration test verifies `collprovider = 'b'`, `collisdeterministic = true`, 100% parity with Python `sorted()` across mixed ASCII, accented, decomposed and Korean strings, and Unicode case folding (`upper('é') = 'É'`).
- **CI-only workflow, supply-chain, CycloneDX SBOM and code hygiene checks (`.github/workflows/tests.yml`):** Keeps all 11 required check names and zero new runtime dependencies while adding:
  - SHA-256 verified `rhysd/actionlint` `v1.7.12` in `hygiene`;
  - `zizmor==1.32.0` (`--offline`), `pip-audit==2.10.1` (`--no-deps --disable-pip` across all four `requirements/*.txt`), CycloneDX SBOM generation checks (`cyclonedx-bom==9.0.0` on `requirements/*.txt` and built-in `npm sbom --sbom-format cyclonedx --package-lock-only` on `skills/semantic-crosscheck/adapters/cube`), `complexipy==9.0.0` (`<= 50` on `tools/` plus top-10 cognitive complexity summary on package scripts), `vulture==2.16` (`--min-confidence 80`), and `deptry==0.25.1` on package scripts in `static`;
  - Expanded `ty==0.0.107` static type checks from 13 to 41 clean core and tool modules (`5` tools + `36` package modules).

## Install

For the developer tools, clone the tagged source with `git clone --branch v0.31.1 --depth 1 https://github.com/Technoetic/semantic-crosscheck.git`. To install the plugin with Codex:

```text
codex plugin marketplace add Technoetic/semantic-crosscheck --ref v0.31.1
codex plugin add semantic-crosscheck@semantic-crosscheck-local
```

## Known limitations

- `tools/check_unicode.py` rejects explicit Bidi control and `Default_Ignorable` smuggling code points; it is not a visual homoglyph detector (e.g. Cyrillic/Greek look-alikes) or a SQL/TOML semantic sandbox.
- `tools/build_release_zip.py` guarantees timezone-independent bytes for the same Python/zlib version and target commit; zlib implementation differences across platforms can produce different compressed streams with identical extracted contents.
- `ty` (`0.0.107`) checks 41 clean core and tool modules (`36/75` package modules plus `5` tools) rather than the entire codebase; `complexipy` enforces a ceiling on `tools/` while reporting top-10 cognitive complexity hotspots on existing package scripts without altering engine code.
- Operational engine behavior, runtime requirements (`requirements/*.txt`) and the Cube `1.8.3` adapter lockfile are unchanged; the five upstream npm advisories in the Cube adapter tree remain upstream-bound.
- `semantic_crosscheck/__init__.py` version increments to `0.31.1`, which updates `engine_sha256` in stage provenance; rerun operational stages after upgrading.
