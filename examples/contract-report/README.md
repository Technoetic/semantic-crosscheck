# Synthetic opt-in contract/report example

Run the two commands in [the contract-report guide](../../docs/contract-report.md).
The offline semantic-preflight command passes for the matching authored files.
Report lists it as required, but remains `not_run` until real operational stages
are present. The example supplies no operational stage receipts.

`reviewed` is an unauthenticated example assertion. Matching metadata is not proof
of SQL meaning, a correct business definition or a shared data snapshot. The Gold
reference exists for normal configuration validation; semantic-preflight does
not read or execute its body.
