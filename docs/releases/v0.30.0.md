# semantic-crosscheck v0.30.0 — what did one more check catch?

Release date: 2026-11-19.

## What it is

This release adds two developer tools for evaluating a change to a set of checks. One replays a synthetic inventory experiment. The other compares paired observations and checks the numbers printed in the release note against those observations.

## Highlights

The baseline compares two query outputs. The candidate also compares them with independently authored expected rows. One held-out SKU had quantities 3 and 7 and two tags. Both queries returned 20; the expected result was 10. Both queries also dropped a different SKU with 4 units and no tag. The added check caught both errors. The baseline detected one of the three erroneous held-out cases, the candidate detected all three, and both accepted the two clean cases.

## Install

For the developer tools, clone the tagged source with `git clone --branch v0.30.0 --depth 1 https://github.com/Technoetic/semantic-crosscheck.git`. To install the plugin with Codex:

```text
codex plugin marketplace add Technoetic/semantic-crosscheck --ref v0.30.0
codex plugin add semantic-crosscheck@semantic-crosscheck-local
```

## Known limitations

Five cases were used for development. A separate agent wrote five held-out examples using the known fixture schema and business rule. They became public regression fixtures after the first evaluation. The result describes this synthetic SKU scenario. The paired experiment runs SQLite queries and the plugin's production row comparators. It measures neither operational error frequency nor runtime cost. The Markdown checker verifies the marked table's source; surrounding prose is reviewed separately.
